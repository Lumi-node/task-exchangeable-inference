# Task Exchange

## Statistical inference with synthetic data via **task exchangeability**

<div align="center">
  <img src="assets/logo.png" alt="Task Exchange logo" width="120"/>
</h1>

### A unified Python library for generating, sharing, and analysing synthetic datasets under the task‑exchangeability framework.

[![PyPI version](https://img.shields.io/pypi/v/exchangelib.svg)](https://pypi.org/project/exchangelib/)

## ✨ Features

<div class="grid cards">

|   |   |   |
|---|---|---|
|<img src="assets/icon-generate.svg" width="48"/>|**Synthetic Data Generation**|Create task‑exchangeable synthetic datasets from any real‑world source, preserving statistical properties while guaranteeing privacy.|
|<img src="assets/icon-analyze.svg" width="48"/>|**Exchangeability Inference**|Run the full statistical pipeline—model fitting, hypothesis testing, and confidence interval estimation—tailored to task‑exchangeable scenarios.|
|<img src="assets/icon-visualize.svg" width="48"/>|**Interactive Visualisation**|Built‑in Matplotlib & Plotly helpers for visualising task‑exchangeability diagnostics, posterior distributions, and power curves.|
|<img src="assets/icon-cli.svg" width="48"/>|**Command‑Line Interface**|A lightweight CLI (`exchangelib`) for quick experiments without writing any code.|
</div>
